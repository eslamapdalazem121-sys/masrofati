مصروفاتي B — نسخة التثبيت (تشتغل بدون إنترنت)
==========================================

كل الملفات هنا في مجلد واحد (من غير مجلدات فرعية) عشان ترفعها بسهولة حتى من الموبايل.
تتحط على أي استضافة https مجانية، وبعد كده تثبّت التطبيق من المتصفح ويشتغل بدون نت.

الطريقة 1 (الأضمن، مجانية دايمًا): GitHub Pages — من الموبايل أو الكمبيوتر
1) اعمل حساب مجاني على github.com (تأكيد الإيميل).
2) New repository  ←  الاسم: masrofati  ←  اختار Public  ←  Create repository.
3) فك ضغط الـ ZIP على الموبايل (من تطبيق الملفات: ضغطة مطوّلة ← Extract).
4) في الـ repository: Add file ← Upload files ← اختار كل الملفات اللي في المجلد مرة واحدة ← Commit changes.
5) Settings ← Pages ← Source: Deploy from a branch ← Branch: main ← Folder: / (root) ← Save.
6) استنى دقيقة أو اتنين وارجع لنفس الصفحة: هيظهر لينك زي:
      https://اسم-حسابك.github.io/masrofati/
7) افتح اللينك في كروم ← ⋮ ← «تثبيت التطبيق».

الطريقة 2: Netlify Drop (app.netlify.com/drop)
- ارفع الـ ZIP أو المجلد. ملحوظة: لو ظهر عندك علامة قفل 🔒 على الموقع وبانر بيقول إن
  production deploys متوقفة، يبقى رصيد حسابك خلص ومش هيرفع. استخدم الطريقة 1.

لتحديث النسخة اللي على GitHub (لما أبعتلك ملفات جديدة):
1) فك ضغط الملفات الجديدة.
2) افتح الـ repository بتاعك ← Add file ← Upload files ← اختار كل الملفات الجديدة (بنفس الأسماء، هتحل محل القديمة) ← Commit changes.
3) استنى 2 لـ 10 دقايق (GitHub بياخد وقت)، وبعدها افتح التطبيق المثبّت وإنت متصل بالنت:
   الإعدادات ← «تثبيت التطبيق» ← «🔄 تحديث التطبيق الآن». هيعيد التشغيل بالنسخة الجديدة.
   (رقم النسخة بيظهر في نفس المكان.)

نقل بياناتك من نسخة Claude للنسخة دي (أو العكس):
1) في النسخة اللي فيها البيانات: ادوس 💾 ← «📤 انسخ بياناتي (كود)».
2) افتح النسخة التانية: 💾 ← «📥 حط بيانات من كود» ← «📋 لصق من الحافظة» ← «استبدل بياناتي بالبيانات دي».
   (بيتحفظ نسخة أمان من بياناتك الحالية قبل الاستبدال.)

حساب بالإيميل + مزامنة بين الأجهزة (Firebase):
- لازم تجهّز مشروع Firebase مرة واحدة: Authentication ← Sign-in method ← Email/Password ← Enable،
  وBuild ← Firestore Database ← Create database، وبعدين Rules (انسخ القواعد اللي بعتهالك واضغط Publish).
- بعد كده في التطبيق: الإعدادات ← «الحساب والمزامنة» ← حساب جديد/دخول. نفس الإيميل على أي جهاز = نفس البيانات.

بعد التثبيت:
- افتح التطبيق مرة واحدة وإنت متصل بالنت واستنى كام ثانية. من الإعدادات ← «تثبيت التطبيق» لازم تشوف
  «✅ جاهز للعمل بدون إنترنت». بعد كده بيفتح من غير نت حتى الخطوط.
- بياناتك بتتحفظ على الجهاز ده بس. للنقل: النسخ الاحتياطي ← تصدير كملف، وبعدين استيراد نسخة.
- لو عدّلت الملفات وعايز التحديث يوصل: ارفع الملفات الجديدة (بنفس الأسماء)، وغيّر رقم CACHE في sw.js
  (masrofati-b-v7 ← v8)، وافتح التطبيق وإنت متصل بالنت مرتين.
